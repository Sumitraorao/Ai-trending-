# 500 AI Agents Web App

This is a Next.js full-stack web application styled with Tailwind CSS, displaying a curated list of AI agents cloned from the ashishpatel26/500-AI-Agents-Projects repository.

## Features
- Fully working web app listing ready-to-use and trending AI agents.
- Strict Light Theme (no dark theme, no black colors anywhere in the UI).
- Built using Next.js 16 and Tailwind CSS v4.

## Getting Started

1. Install dependencies:
   npm install

2. Run the development server (in background):
   npm run dev &

3. Open http://localhost:3000 with your browser to see the result.

## Data Source
The agents data is parsed from the 500-AI-Agents-Projects repository using parse_agents.py and stored in src/data/agents.json.
